# Student Performance Analysis

## Project Overview

This project focuses on analyzing the academic performance of 10 fictional students across five subjects using R and RStudio.

The aim is to identify performance patterns, calculate subject averages, examine relationships between subjects, and present findings through data visualizations.

## Tools and Technologies
- R
- RStudio
- ggplot2
- Microsoft Excel

## Dataset

The dataset contains 10 student records and five academic subjects:
- Mathematics
- English
- Biology
- Physics
- Geography

## Analysis Performed
- Data importation and inspection
- Data preparation and cleaning
- Calculation of subject averages
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Data visualization

## Key Findings
- Geography recorded the highest average performance.
- Physics recorded the lowest average performance.
- Mathematics recorded an average of 76.4 marks.
- A scatter plot was used to explore the relationship between Mathematics and Physics performance.

## Visualizations

The project includes:
1. A bar chart comparing average marks across subjects.
2. A scatter plot examining Mathematics and Physics performance.

## Project Purpose

This project demonstrates practical application of statistical analysis and data visualization in educational data.
